# 1.0.2 release notes

Same text for both stores. No em dashes, plain language, only claims the build
actually delivers.

## What's New

Scheduling fixes, a much shorter first run, and quieter notifications.

- Workouts are no longer scheduled during school, work or sleep, and no longer
  land the minute your alarm goes off.
- Weekday mornings are avoided unless that is genuinely your only free window.
- Rescheduling now lets you pick a date and time yourself.
- Sessions already sitting at an impossible time get moved for you.
- Push days no longer include pull exercises.
- The first run walkthrough is four steps instead of fourteen, and every step
  stays fully on screen.
- Notifications are quieter and more accurate: at most one a day, never late at
  night or before you are up, and no more nudges on a rest day.
- Fixes now reach you promptly instead of waiting for an app restart.

## Shorter variant, if the field is tight

Scheduling fixes: no more sessions during school, work or sleep, and you can now
pick a date and time yourself when rescheduling. The first run walkthrough is
four steps instead of fourteen. Notifications are quieter and more accurate.
Push days no longer include pull exercises.
